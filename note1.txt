1. What are profiles in spring boot ? How it works?

profiles are a way to set different sets of configuration of an application based on different runtime environment or deployment senarios.

profiles are typically defined in the `application.properties` or `application.yml` file using the `spring.profiles.active` property.

advantages:-
  1) Configuration seperation: With profiles, you can define
    seperate configuration files for different environment ,
    such as deployment, testing, staging and production. 

  2) Application Properties: You can define profile specific properties in the `application-{profile}.properties` or `application-{profile}.yml` files.
       
  3) Command -line or Environment activation: Profiles can be a activated using command-line arguments
        eg :- `spring.profiles.acivate` property to `dev` to
        strat your application at profile environment 

   4) Default Profile : If no profile is explicitly activated , Spring Boot uses `default` profile by default.


   2. How does Spring Boot helps building microservices archtecture?

      1) Light -weight and Stand-alone : Spring-boot allow you to build stand alone micro-services that can run independently.

      2) Service registration and discovery: Eureka is a service registry and dicovey server that allow micro-sevices to register themselves and discover other services.

      3) Distributed Configuration: Spring cloud allow you to externalize config properties and retrive them from config server.

      4)Load balencing and Resilance : It helps to Distribute incoming requests and provide fault tolerance by automating routing requests to healthy instances.

      5) Circuit Breaker pattern: It helps in managing faults and failures in distributed systems by providing fallback mechanisms.

      6) API Gateway: Spring Cloud Gateway acts as an entry point for incoming requests and can perform routing, filtering and load balencing.

      7) Monitoring and Metrics: Spring boot Actuators provides production ready end-points for monitoring and managing micro-services.

An interface is used to achieve full Abstraction

All methods in an interface are public and abstract by default and '
alll variables declaredc are constants i.e public , static and final
